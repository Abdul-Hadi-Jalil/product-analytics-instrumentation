# Event design

The event model organizes tracking around user goals and lifecycle transitions:

- Registration, authentication, and profile completion
- Plan selection, checkout, and payment outcomes
- Account evaluation and funding states
- Identity verification progression
- Payout requests and disbursement
- Subscription changes
- Affiliate application and approval
- Dashboard and journal engagement

Events use stable names, explicit properties, and shared context. QA validates sequence, payload shape, duplicate suppression, and failure-path coverage.
